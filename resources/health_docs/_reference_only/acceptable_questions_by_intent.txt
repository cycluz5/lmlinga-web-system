LMLinga Health Chatbot — Acceptable Questions BY REAL INTENT
=============================================================================
NOT part of the indexed corpus. Reference/testing document only.

HOW THIS DIFFERS FROM THE PREVIOUS LIST
------------------------------------------
The earlier "scenarios" file varied wording but kept asking the same
DEFINITION intent every time ("What is X?" / "Ano ang X?" / "Uno an X?").
This file instead uses the pipeline's own intent classifiers, so each
variant is a genuinely different question type that gets routed to a
different section of the source document.

Source (read directly from code, not guessed):
- English intents: detectEnglishSupportIntent() — RagService.php:6169
- Tagalog intents: detectTagalogSupportIntent() — RagService.php:6577
- Bikol intents:   detectBikolIntent()          — RagService.php:3209

IMPORTANT PIPELINE DIFFERENCE FOUND WHILE STUDYING THE CODE
----------------------------------------------------------------
Bikol-Iriga does NOT have a separate "prevention" intent bucket the way
English and Tagalog do. In detectBikolIntent(), both prevention-style words
(maiwasan, likay, pag-iwas) and treatment/care-style words (gibuhon, gamot,
ataman) resolve to the SAME intent: "management". English and Tagalog keep
"prevention" and "treatment" as two separate intents. This means a Bikol
prevention question and a Bikol treatment question for the same illness are
expected to surface the SAME section of the document — that is correct,
intended pipeline behavior, not a bug, but it is worth knowing when testing.

Bikol also has two intents English/Tagalog do not have:
- "warning" — urgent/unsafe-symptom questions (e.g. mentions "ospital",
  "magpakonsulta", "positive" test result, convulsions). See
  isBikolWarningQuestion() — RagService.php:3339.
- "schedule" — age/month/year eligibility questions (e.g. "bakuna sa 9 na
  bulan"). See isBikolScheduleQuestion() — RagService.php:3409.

Whether an intent question actually returns a good answer ALSO depends on
whether the target document has a real section for that intent (a
"Symptoms" or "Causes" heading, etc.) — not just whether the intent is
recognized. A recognized intent with no matching section in the document
will still fall back to the definition/general text.
