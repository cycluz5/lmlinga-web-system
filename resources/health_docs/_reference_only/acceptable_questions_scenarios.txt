LMLinga Health Chatbot — Acceptable Question SCENARIOS (multiple phrasings)
=============================================================================
NOT part of the indexed corpus. Reference/testing document only — kept
outside the en/tl/bcl language folders so it is never picked up by
`php artisan health:index`.

WHY MULTIPLE PHRASINGS
------------------------
The chatbot only answers when it can match a document that is genuinely
ABOUT the topic (checked by title/heading, not just body mentions — see the
identity-gate logic in app/Services/RagService.php). Different phrasings of
the "same" question can extract different keywords and be treated
differently by that gate. Testing several phrasings per topic — formal,
casual, symptom/concern-framed, and prevention-framed — is the way to find
phrasings that fail even though the topic itself is supported, versus
phrasings that fail because the topic genuinely has no document (like fever
right now).

Each topic below lists 4 phrasing variants per language. If one variant
fails while others for the same topic succeed, that specific phrasing is
worth flagging as a retrieval gap even though the topic itself is covered.
